# PlaceWell Android Application

A complete Android application for service booking and management. This project includes features for users, workers, and administrators to manage service requests, orders, negotiations, and payments.

## Features

- User dashboard for booking services
- Worker dashboard for managing orders
- Admin dashboard for managing users, workers, and orders
- Real-time chat functionality
- Negotiation system for pricing
- Order tracking
- Payment integration

## Technologies Used

- Java (Android)
- Firebase for backend services
- Google Maps API
- Real-time database

## Project Structure

The project follows a standard Android application structure with activities for different user roles and components for managing services, orders, and users.

## Setup Instructions

1. Clone the repository
2. Open in Android Studio
3. Sync the project with Gradle files
4. Add your google-services.json file (for Firebase integration)
5. Build and run the application

## Important Files

- `app/google-services.json` - Firebase configuration file
- Various activity files for different user interfaces
- Adapters for list views and recycler views
- Model classes for data structures
